PKGSmith 1.0.8 Release Notes

Added

  • Added a package filename setting with an output preview and validation for invalid filenames.
  • Added support for file-only and script-only PKG builds through the CLI and script-only builds in the app.

Changed

  • Updated ConfettiSwiftUI to 3.0.0.
  • PKG filenames now default to the saved project name, then the app bundle name for unsaved projects, or `Installer.pkg` when neither is available.

Fixed

  • Fixed PKG builds creating a hidden `.pkg` file when no app bundle was selected.
  • Improved license validation compatibility when Polar retires an API version.
