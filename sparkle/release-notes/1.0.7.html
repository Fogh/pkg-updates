PKGSmith 1.0.7 Release Notes

Changed

  • Updated Homebrew cask generation for current Homebrew releases and added style validation before publishing.
  • Updated Sparkle to 2.9.5, AcknowList to 3.4.3, and Sentry Cocoa to 9.26.0.
  • Removed the obsolete admin-password project setting; older project files remain compatible.

Fixed

  • Fixed PKG rebuilds so stale signed artifacts cannot be reported as a successful new build.
  • Fixed Installer background metadata and ensured PKG installers update the app in `/Applications` instead of relocating another copy.
  • Added validation for unsafe payload destinations and reliable temporary build cleanup.
